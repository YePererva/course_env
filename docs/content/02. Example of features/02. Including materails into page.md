# Including materials into web-page

## Embedding online materials

### Youtube

Open any video on youtube, click `Share` → `Emmbed`, that it will provide the piece of code that can be inserted directly into note.

The link would look alike:

```HTML
<iframe width="560" height="315"
    src="https://www.youtube.com/embed/tJYrKwFvuhM?si=0k298Gd3JSsiuiIN"
    title="YouTube video player" frameborder="0" 
    allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share"
    referrerpolicy="strict-origin-when-cross-origin" allowfullscreen>
</iframe>
```

## Attachments of file as downloadable links

To add downloadable files `markdown`, enable in `mkdocs.yml` the following :

```YAML
markdown_extensions:
  - attr_list
```

and then in .md file add `download` attribute to your link:

```markdown
[file.ext](../folder/subfolder/file.ext){:download}
```

You can even provide the name for downloaded file:

```markdown
[file.ext](../folder/subfolder/file.ext){:download="awesome-file"}
```

For example:

```markdown
# to download
[datasheet](content/02.%20Example%20of%20features/references/datasheets/A000066-datasheet.pdf){:download}
# of set in system, this will open preview with Adobe plugin for browser
[datasheet](content/02.%20Example%20of%20features/references/datasheets/A000066-datasheet.pdf)
```
