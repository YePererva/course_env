# Navigation

Official [documentation](https://squidfunk.github.io/mkdocs-material/setup/setting-up-navigation/#section-index-pages-with-section-index-pages) 

Previously, we set the footer for navigation via editing `features` components of `mkdocs.yml` file :

```YML title="mkdocs.yml"
features:
    - navigation.footer
```

I would like to change for the following:

```YML title="mkdocs.yml"
features:
    - navigation.footer
    - navigation.indexes
```

`navigation.indexes` would allow to use `index.md` files within section as direct attachment. Useful for providing overview pages.

It would be also nice to have breadcrumbs added via `navigation.path`, but as of moment  of writing this, it is a feature for sponsors only.
