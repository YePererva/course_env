# Adding markdown extensions

To adjust all of that:

```YAML
markdown_extensions:
  - attr_list
  - toc:
      permalink: true
  # for tasklists
  - pymdownx.tasklist
  # for rendering tables
  - tables
  # for code syntax highlight
  - pymdownx.highlight:
      anchor_linenums: true
      line_spans: __span
      pygments_lang_class: true
  - pymdownx.inlinehilite
  - pymdownx.snippets
  # for MathJax support
  - pymdownx.arithmatex:
      generic: true
  # for diagramming
  - pymdownx.superfences:
      custom_fences:
        - name: mermaid
          class: mermaid
          format: !!python/name:pymdownx.superfences.fence_code_format
  # for callouts / warnings
  - pymdownx.blocks.admonition #previously, just "admonition"
  - pymdownx.details
  - footnotes
  # for tabbed content
  - pymdownx.tabbed:
      combine_header_slug: true
      alternate_style: true

  # for rendering emoji
  - pymdownx.emoji:
      emoji_index: !!python/name:material.extensions.emoji.twemoji
      emoji_generator: !!python/name:material.extensions.emoji.to_svg
```

and, in the `theme` chapter of `mkdocs.yml`:

```YAML
custom_dir: overrides
features:
    - content.code.copy
    - content.code.annotate

extra_javascript:
  - javascripts/mathjax.js
  # this newer call for MathJax
  - https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-mml-chtml.js
  # this is older, don't use it anymore
  # - https://unpkg.com/npm/mathjax@3/es5/tex-mml-chtml.js
```

Than, create in your project root folder subfolder `overrides` with extra subfolder `javascripts`. Place inside the `js` file named `mathjax.js` with the following content:

```js
window.MathJax = {
    tex: {
      inlineMath: [["\\(", "\\)"]],
      displayMath: [["\\[", "\\]"]],
      processEscapes: true,
      processEnvironments: true
    },
    options: {
      ignoreHtmlClass: ".*|",
      processHtmlClass: "arithmatex"
    }
  };
  
  document$.subscribe(() => { 
    MathJax.startup.output.clearCache()
    MathJax.typesetClear()
    MathJax.texReset()
    MathJax.typesetPromise()
  })
```

If you need to use type some simple chemistry in the body of the document, than add this in the beginning of the `javascripts/mathjax.js` file.  

```JS
MathJax.Hub.Config({
  TeX: {
    extensions: ["[Contrib]/mhchem/mhchem.js"]
  }
});
```

## Remarks 

### Admonitions

a.k.a. callouts

Currently, admonitions are connected with `admonition` (official [documentation](https://squidfunk.github.io/mkdocs-material/reference/admonitions/)), however, seems to be prepare to be replaces with `pymdownx.blocks.admonition` which is using a different syntax ([documentation](https://facelessuser.github.io/pymdown-extensions/extensions/blocks/plugins/admonition/)) . Keep in mind, when deciding.


### Issues with rendering math

There are spotted some problems with rendering degree sign in equations while using MathJax. Some workaround is spotted [here](https://github.com/squidfunk/mkdocs-material/issues/484)
