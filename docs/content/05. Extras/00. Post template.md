# Template for the post

## Structure of the chapter note folder

``` title="Structure of chapter template folder"
→ chapter_name
    → index.md
    
    → ... .md
    → any other sub-chapter md-files
    → ... .md
    
    → images
	    // screenshots, or other images not to be post-processed
        → other   
        // raw file to be converted into illustrations
        → src
	        // one sub-folder per used software     
            → kicad
            → inkscape
        // output of processing files from src folder with the same
        // sub-folder structure as src
        → render
        
    → references  // datasheets, articles, etc.
	    → application_notes
	    → code_snippets
	    → datasheets
	    → lectures
	    → manuals
	    → patents
	    → publications
	    → regulatory
```

I have this in `.tempaltes` folder of the root project.  Each folder in template folder contains empty `.gitkeep` file.
