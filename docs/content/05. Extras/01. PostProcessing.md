# Post Processing

as of now, the actual versions are:

- KiCad 9.0.0 
- Inkscape 1.4.0

To install them both on Ubuntu 24.04 LTS from under WSL

```bash
sudo apt update
sudo add-apt-repository --yes ppa:kicad/kicad-9.0-releases
sudo apt install --install-recommends kicad -y
sudo apt full-upgrade -y
sudo apt install inkscape -y
```

Alternative way to add padding to svg via inkscape:
https://graphicdesign.stackexchange.com/questions/25066/inkscape-padding-or-margin-on-export

Don't forget to adjust the `.gitignore` to drop some intermediate python files.
