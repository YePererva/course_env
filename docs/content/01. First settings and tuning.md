# First settings and cosmetics

Official [documentation](https://www.mkdocs.org/getting-started/#creating-a-new-project)

## Renaming the project

Edit the file `mkdocs.yml`. By default, it contains:

```YML
site_name: My Docs
```

Let's change it to:
```YAML
site_name: Educational course web-site
site_url: https://sitename.example
theme:
	name: material
```

Save the file. Note:

- that the site is auto-updated (live preview)
- `yml` files don't like mixing indentation with tabs and spaces
- `yml` can tolerate Cyrillic symbols

```YAML
site_name: Додаток до курсу
```

## Cosmetics

### Theme switch: Light / Dark / System

As per [documentation](https://squidfunk.github.io/mkdocs-material/setup/changing-the-colors/#automatic-light-dark-mode)

```YAML
theme:
  name: material 
  palette:

    # Palette toggle for automatic mode
    - media: "(prefers-color-scheme)"
      toggle:
        icon: material/brightness-auto
        name: Switch to light mode

    # Palette toggle for light mode
    - media: "(prefers-color-scheme: light)"
      scheme: default 
      toggle:
        icon: material/brightness-7
        name: Switch to dark mode

    # Palette toggle for dark mode
    - media: "(prefers-color-scheme: dark)"
      scheme: slate
      toggle:
        icon: material/brightness-4
        name: Switch to system preference
```

It creates makes the toggle-switch, that by default gets the scheme of the user browser, but if click, it forces the light mode, and than it forces the dark mode. Afterwards, it loops through the cycle.

If making some electronics courses:

- `teal` looks like [Arduino forum](https://forum.arduino.cc/) theme
- `indigo` looks like STMicroelectronics

Other electronics manufacturer have other branded boards in colours:

- Texas Instruments : red
- Espressif Systems: black

More [reading](https://squidfunk.github.io/mkdocs-material/setup/changing-the-colors/) about usable symbols for switching themes. 

## Adjusting fonts

MKdocs is compatible with Google Fonts. 
In case if font adjustment is needed, than add needed fonts:

```YAML
theme:
  font:  
    text: Red Hat Flex
    code: Red Hat Mono
```

**P.S.:** `Roboto Flex` looks better to me. Anyway check the support of font for your language
