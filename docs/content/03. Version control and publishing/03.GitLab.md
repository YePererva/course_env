# Publishing to GitLab Pages

## Monorepository way

Create the `.gitlab-ci.yml` file in the root of your mono-repository with the following content:

```YML title=".gitlab-ci.yml"
pages:
  stage: deploy
  image: python:latest
  script:
    - pip install -r prerequisites.txt
    - mkdocs build --site-dir public
  cache:
    key: ${CI_COMMIT_REF_SLUG}
    paths:
      - .cache/ 
  artifacts:
    paths:
      - public
  rules:
    - if: '$CI_COMMIT_BRANCH == $CI_DEFAULT_BRANCH'
```

THis is based on example `.gitlab-ci.yml` official [documetation](https://squidfunk.github.io/mkdocs-material/publishing-your-site), but is rather installing not only `mkdocs-material`, but the full list of defined dependencies from the specified file.

Thus, when a new commit is pushed to the default branch (typically `master` or `main`), the static site is automatically being built and deployed.
