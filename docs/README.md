# Overall idea

- use note taking application as note manager (topics, etc.). For example
	- Obsidian
	- VSCode with plugins
- use (if needed) [InkScape](https://inkscape.org/release/), [KiCAD](https://www.kicad.org/download/), other for ilustration(s)
- keep it as GitHub repository
- export Github Repository to
	- GitHub pages
	- local server for self-hosting


## Used tools

- [mkdocs](https://www.mkdocs.org/) + [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/)
	- generator of static web-pages with needed functionality and "web-engine"
- GitHub + Github pages
	- notes storage and hosting platform
