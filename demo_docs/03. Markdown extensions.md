# Markdown extensions

If you are running some sort of technical repo, that you'd probably need:

- diagramming:
	- mermaid diagrams
- code blocks
	- code blocks
- user warnings
	- callouts
- switchable content depending on user system (various code for different operating systems)
	- tabbed content
- render of math equations:
	- KATEX or MathJax: math [documentation](https://squidfunk.github.io/mkdocs-material/reference/math/)
- some fun / special icons
	- emoji : [documentation](https://squidfunk.github.io/mkdocs-material/reference/icons-emojis/#search)

To adjust all of that:

```YAML
markdown_extensions:
  - attr_list
  # for code syntax highlight
  - pymdownx.highlight:
      anchor_linenums: true
      line_spans: __span
      pygments_lang_class: true
  - pymdownx.inlinehilite
  - pymdownx.snippets
  # for diagramming
  - pymdownx.superfences:
      custom_fences:
        - name: mermaid
          class: mermaid
          format: !!python/name:pymdownx.superfences.fence_code_format
  # for callouts / warnings
  - admonition
  - pymdownx.details
  # for tabbed content
  - pymdownx.tabbed:
      alternate_style: true
  # for rendering emoji
  - pymdownx.emoji:
      emoji_index: !!python/name:material.extensions.emoji.twemoji
      emoji_generator: !!python/name:material.extensions.emoji.to_svg
```
