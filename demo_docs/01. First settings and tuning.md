# First settings and tuning

Official [documentation](https://www.mkdocs.org/getting-started/#creating-a-new-project)


Edit the file `mkdocs.yml`. By default, it contains:

```YML
site_name: My Docs
```

Let's change it to:
```YAML
site_name: Educational course web-site
site_url: https://sitename.example
theme:
	name: material
```

Save the file. Note:
- that the site is auto-updated
- `yml` files don't like indentation with tabs
- `yml` can tolerate Cyrillic symbols

```YAML
site_name: Додаток до курсу
```

Since we are using the VSCodium, let's add a few extensions for easier life:

- [YAML](https://open-vsx.org/vscode/item?itemName=redhat.vscode-yaml) from RedHat, will highlight the errors in YAML files if we'll make any

To make it work, navigate to VSCodium settings -> `User` -> `extensions` -> `YAML`. Here we can see adjustable settings, but we are looking for it's code representation.

Than adjust it to be:
```JSON
{
    "redhat.telemetry.enabled": false
    "yaml.schemas": {
        "https://squidfunk.github.io/mkdocs-material/schema.json": "mkdocs.yml"
      },
      "yaml.customTags": [
        "!ENV scalar",
        "!ENV sequence",
        "!relative scalar",
        "tag:yaml.org,2002:python/name:material.extensions.emoji.to_svg",
        "tag:yaml.org,2002:python/name:material.extensions.emoji.twemoji",
        "tag:yaml.org,2002:python/name:pymdownx.superfences.fence_code_format"
      ]
}
```
Those are parts of [documentation](https://squidfunk.github.io/mkdocs-material/schema.json)
